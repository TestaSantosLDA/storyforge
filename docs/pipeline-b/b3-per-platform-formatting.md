# Pipeline B · Stage 3 — Per-Platform Formatting

Stage B3 turns each rendered clip into ready-to-post variants for YouTube Shorts, TikTok and Instagram Reels, with platform-specific captions, hashtags, cover frames and calls to action pointing back to the full episode.

## Position in the pipeline

- B2 Vertical Re-assembly → **B3 Per-Platform Formatting** → B4 Publish.
- Trigger: clip status `formatting`. No GPU needed.

## Inputs

- Rendered vertical clip and its hook title (B1/B2).
- The full episode's YouTube URL, title and series playlist (Pipeline A Stage 5).
- Music attribution text, if any.

## Per-platform output

|  | YouTube Shorts | TikTok | Instagram Reels |
| --- | --- | --- | --- |
| Video | Same 1080×1920 file | Same file | Same file |
| Caption / title | Short title with the hook | Caption with hook and hashtags | Caption with hook and hashtags |
| Call to action | Link the full episode as the Short's related video | "Full episode on our YouTube channel" (links aren't clickable in captions) | Same as TikTok |
| Hashtags | Up to 3 | Platform-appropriate set | Platform-appropriate set |
| Cover | Chosen frame from the clip | Chosen frame | Chosen frame |
| Audience | Channel setting: not made for kids | Account setting | Account setting |

Captions and hashtags are generated by Claude for each platform's own discovery style, honestly describing the clip.

## Automated QA

| Check | Pass condition |
| --- | --- |
| Platform spec | Length, resolution and file size within each platform's current limits (kept in config) |
| Text | Caption length within each platform's limit; no trademarked names; no misleading claims |
| Call to action | Present on every variant; the YouTube Short references the right full episode |
| Attribution | Music attribution included where required |
| Cover | Frame shows a character clearly, no mid-transition blur |

Failures regenerate up to 3 times; then `needs_attention`.

## Scenarios

| # | Scenario | What happens | Result |
| --- | --- | --- | --- |
| 1 | Happy path | Three variants prepared | `clip_ready` (B4) |
| 2 | A platform changes its limits | Update the config values; no code change | n/a |
| 3 | Caption too long for a platform | Regenerate shorter | retry |
| 4 | Full episode URL missing | Should be impossible after Stage 5; flag | `needs_attention` |
| 5 | Reviewer wants to skip a platform for a clip | Allowed in B4; the variant is marked skipped | unchanged |

## Status transitions

| From | Event | To |
| --- | --- | --- |
| `formatting` | QA passes | `clip_ready` (B4) |
| `formatting` | QA fails 3 times or URL missing | `needs_attention` |
| `needs_attention` | Resume | `formatting` |

## Decisions

- One video file, three platform variants differing in text, hashtags, cover and call to action.
- Platform limits live in config, so changes don't need code.
- Every variant points back to the full YouTube episode.
